Calculation Drill: 20 Problems, Nothing but Numbers

前兩冊重觀念，這一冊只練手。每題都是「給數字 → 算統計量 → 下判決」，詳解壓縮成代入與答案兩三行。建議計時：每題 3 分鐘，卡住就先看答案，把卡住的那一步抄在紙上。

Sets 1 and 2 focused on concepts; this one is pure muscle memory. Every item is "given numbers → compute the statistic → decide". Solutions are compressed to substitution and answer. Time yourself: three minutes per problem; if stuck, peek at the answer and write down the step that stopped you.

20 題 / 20 problems 純計算 / computation only 繁中 × English 建議 3 分鐘/題
使用方式 / How to use
先不要點開詳解。拿一張紙寫下四行：SE → 統計量 → 臨界值或 p → 判決。四行都寫完才對答案。統計量用 scipy 重算過，四捨五入到小數四位。
Do not open the solution first. On paper write four lines: SE → statistic → critical value or p → decision. Check only after all four are done. All statistics were recomputed with scipy and rounded to four decimals.
Q1★Z · 右尾
μ₀=60, σ=9, n=36, x̄=63。在 α=.05 右尾檢定 Ha: μ>60。求 SE、z、p 值與判決。
μ₀=60, σ=9, n=36, x̄=63. Test Ha: μ>60 at α=.05 (upper tail). Find SE, z, p and the decision.
顯示詳解 / Show solution
SE = 9/√36 = 1.5；z = (63−60)/1.5 = 2.000；p = 1−Φ(2) = 0.0228；z₀.₀₅=1.645。
SE = 9/√36 = 1.5; z = (63−60)/1.5 = 2.000; p = 1−Φ(2) = 0.0228; z₀.₀₅=1.645.
Q1　z=2.000 > 1.645，p=.0228 < .05 → 拒絕 H₀ / Reject H₀.
Q2★Z · 左尾
μ₀=100, σ=20, n=50, x̄=95。在 α=.05 左尾檢定 Ha: μ<100。求 SE、z、p 值與判決。
μ₀=100, σ=20, n=50, x̄=95. Test Ha: μ<100 at α=.05 (lower tail). Find SE, z, p and the decision.
顯示詳解 / Show solution
SE = 20/√50 = 2.8284；z = (95−100)/2.8284 = −1.7678；p = Φ(−1.7678) = 0.0386；−z₀.₀₅=−1.645。
SE = 20/√50 = 2.8284; z = (95−100)/2.8284 = −1.7678; p = Φ(−1.7678) = 0.0386; −z₀.₀₅=−1.645.
Q2　z=−1.768 < −1.645，p=.0386 < .05 → 拒絕 H₀ / Reject H₀.
Q3★Z · 雙尾
μ₀=30, σ=8, n=64, x̄=32.5。在 α=.01 雙尾檢定。求 z、p 值與判決。
μ₀=30, σ=8, n=64, x̄=32.5. Two-tailed test at α=.01. Find z, p and the decision.
顯示詳解 / Show solution
SE = 8/√64 = 1；z = 2.5；p = 2×P(Z>2.5) = 0.0124；z₀.₀₀₅ = 2.576。
SE = 8/√64 = 1; z = 2.5; p = 2×P(Z>2.5) = 0.0124; z₀.₀₀₅ = 2.576.
Q3　|z|=2.5 < 2.576，p=.0124 > .01 → 不拒絕 / Do not reject. （同一個 z 在 α=.05 會拒絕）
Q4★臨界值翻譯
μ₀=60, σ=9, n=36，右尾 α=.01。求 x̄ 尺度上的臨界值 c。
μ₀=60, σ=9, n=36, upper tail at α=.01. Find the critical value c on the x̄ scale.
顯示詳解 / Show solution
SE = 1.5；z₀.₀₁ = 2.3263；c = 60 + 2.3263×1.5 = 63.4895。
SE = 1.5; z₀.₀₁ = 2.3263; c = 60 + 2.3263×1.5 = 63.4895.
Q4　c = 63.4895；決策規則：x̄ > 63.49 就拒絕。

Q6★★t · 右尾
σ 未知：n=16, x̄=52, s=8, μ₀=48。在 α=.05 右尾檢定。求 t、p 值與判決。
σ unknown: n=16, x̄=52, s=8, μ₀=48. Upper-tailed test at α=.05. Find t, p and the decision.
顯示詳解 / Show solution
SE = 8/√16 = 2；t = (52−48)/2 = 2.000，df=15；p = P(t₁₅>2) = 0.0320；t₀.₀₅,₁₅=1.753。
SE = 8/√16 = 2; t = (52−48)/2 = 2.000, df=15; p = P(t₁₅>2) = 0.0320; t₀.₀₅,₁₅=1.753.
Q6　t=2.000 > 1.753 → 拒絕 / Reject. 若誤用 Z，p 會是 0.0228（低估）。
Q7★★t · 雙尾
n=25, x̄=18.4, s=3, μ₀=20，α=.05 雙尾。求 t、p 值與判決。
n=25, x̄=18.4, s=3, μ₀=20, two-tailed at α=.05. Find t, p and the decision.
顯示詳解 / Show solution
SE = 3/√25 = 0.6；t = (18.4−20)/0.6 = −2.6667，df=24；p = 2×P(t₂₄<−2.6667) = 0.0135；t₀.₀₂₅,₂₄=2.064。
SE = 3/√25 = 0.6; t = (18.4−20)/0.6 = −2.6667, df=24; p = 2×P(t₂₄<−2.6667) = 0.0135; t₀.₀₂₅,₂₄=2.064.
Q7　|t|=2.667 > 2.064 → 拒絕 / Reject.
Q8★★t 信賴區間
n=16, x̄=52, s=8，σ 未知。求 μ 的 95% 信賴區間。
n=16, x̄=52, s=8, σ unknown. Compute the 95% confidence interval for μ.
顯示詳解 / Show solution
SE = 2；t₀.₀₂₅,₁₅ = 2.1314；52 ± 2.1314×2 = 52 ± 4.2629。
SE = 2; t₀.₀₂₅,₁₅ = 2.1314; 52 ± 2.1314×2 = 52 ± 4.2629.
Q8　95% CI = [47.7371, 56.2629]。用 1.96 會得到錯誤的較窄區間。
Q9★★χ² · 右尾
σ₀=6, n=16, s=8.4，右尾 α=.05。求 U、臨界值、p 值與判決。
σ₀=6, n=16, s=8.4, upper tail at α=.05. Find U, the critical value, p and the decision.
顯示詳解 / Show solution
U = 15×8.4²/6² = 29.400，df=15；χ²₀.₀₅,₁₅=24.9958；p = P(χ²₁₅>29.4) = 0.0143。
U = 15×8.4²/6² = 29.400, df=15; χ²₀.₀₅,₁₅=24.9958; p = P(χ²₁₅>29.4) = 0.0143.
Q9　29.40 > 24.996 → 拒絕 / Reject，變異數顯著變大。
Q10★★χ² · 雙尾
σ₀=8, n=21, s=11.5，雙尾 α=.05。求 U、兩界與判決。
σ₀=8, n=21, s=11.5, two-tailed at α=.05. Find U, both bounds and the decision.
顯示詳解 / Show solution
U = 20×11.5²/8² = 41.3281，df=20；下界 9.5908、上界 34.1696；p ≈ 0.0068。
U = 20×11.5²/8² = 41.3281, df=20; lower 9.5908, upper 34.1696; p ≈ 0.0068.
Q10　41.33 > 34.17 → 拒絕 / Reject。兩界距 df=20 分別 10.41 與 14.17，不對稱。
Q11★★★β 與 power
μ₀=100, σ=10, n=25, α=.05 右尾。若 μₐ=105，求 c、β、power。
μ₀=100, σ=10, n=25, α=.05, upper tail. If μₐ=105, find c, β and power.
顯示詳解 / Show solution
SE=2；c = 100 + 1.6449×2 = 103.2897；zβ = (103.2897−105)/2 = −0.8551；β = Φ(−0.8551) = 0.1962。
SE=2; c = 100 + 1.6449×2 = 103.2897; zβ = (103.2897−105)/2 = −0.8551; β = Φ(−0.8551) = 0.1962.
Q11　β = 0.1962，power = 0.8038.
Q12★★★樣本數

Continue Q11: raise power to .90 with δ=5, σ=10, α=.05 (upper tail). Find n.
顯示詳解 / Show solution
n = ((1.6449+1.2816)×10/5)² = 34.2554。
n = ((1.6449+1.2816)×10/5)² = 34.2554.
Q12　n = 35（無條件進位，34 的 power 不到 .90）。

Q14★★★兩母體均值
n₁=50, x̄₁=120, σ₁=15；n₂=60, x̄₂=114, σ₂=12；D₀=0，雙尾 α=.05。求 SE、Z、p 與判決。
n₁=50, x̄₁=120, σ₁=15; n₂=60, x̄₂=114, σ₂=12; D₀=0, two-tailed at α=.05. Find SE, Z, p and the decision.
顯示詳解 / Show solution
SE = √(225/50 + 144/60) = √(4.5+2.4) = √6.9 = 2.6268；Z = 6/2.6268 = 2.2842；p = 0.0224。
SE = √(225/50 + 144/60) = √(4.5+2.4) = √6.9 = 2.6268; Z = 6/2.6268 = 2.2842; p = 0.0224.
Q14　|Z|=2.284 > 1.960 → 拒絕 / Reject. 注意是變異數相加，不是 15/√50 + 12/√60.
Q15★★★兩比例 · 檢定
x₁=30/150, x₂=28/200，雙尾 α=.05。求 p̂_pool、SE、z、p 與判決。
x₁=30/150, x₂=28/200, two-tailed at α=.05. Find p̂_pool, SE, z, p and the decision.
顯示詳解 / Show solution
p̂₁=.20, p̂₂=.14；p̂_pool = 58/350 = 0.1657；SE = √(0.1657×0.8343×(1/150+1/200)) = 0.04016；z = 0.06/0.04016 = 1.4940；p = 0.1352。
p̂₁=.20, p̂₂=.14; p̂_pool = 58/350 = 0.1657; SE = √(0.1657×0.8343×(1/150+1/200)) = 0.04016; z = 0.06/0.04016 = 1.4940; p = 0.1352.
Q15　|z|=1.494 < 1.960 → 不拒絕 / Do not reject.

Q17★★二項精確
X~Binomial(20, 0.10)。求 P(X≥5) 與 P(X≥6)。
X~Binomial(20, 0.10). Find P(X≥5) and P(X≥6).
顯示詳解 / Show solution
P(X≥5) = 1 − Σ(k=0..4) C(20,k)(.1)^k(.9)^(20−k) = 0.0432
P(X≥6) = 0.0113。
P(X≥5) = 1 − Σ(k=0..4) C(20,k)(.1)^k(.9)^(20−k) = 0.0432
P(X≥6) = 0.0113.
Q17　0.0432 與 0.0113。若 α=.05 且觀察到 5 個，拒絕 H₀；觀察 6 個更強。

p̂ = 0.38; SE = √(0.3×0.7/100) = 0.04583; z = (0.38−0.30)/0.04583 = 1.7457; p = 2×P(Z>1.7457) = 0.0809.

Q20★★★★混合大題
σ 未知，n=36, x̄=98, s=12, μ₀=95, α=.05 右尾，真實 μₐ=98。求 (a) t、p、判決；(b) 95% 雙側 CI；(c) 對 μₐ=98 的 β 與 power（SE 用 12/√36）。
σ unknown, n=36, x̄=98, s=12, μ₀=95, α=.05 upper tail, true μₐ=98. Find (a) t, p, decision; (b) two-sided 95% CI; (c) β and power against μₐ=98 (use SE = 12/√36).
顯示詳解 / Show solution
(a) SE=2，t=(98−95)/2=1.500，df=35，p=P(t₃₅>1.5)=0.0713，t₀.₀₅,₃₅=1.6896 → 不拒絕。
(b) t₀.₀₂₅,₃₅=2.0301，98±2.0301×2 = [93.9398, 102.0602]。
(c) c=95+1.6449×2=98.2897；zβ=(98.2897−98)/2=0.1449 → β=Φ(0.1449)=0.5576，power=0.4424。
(a) SE=2, t=(98−95)/2=1.500, df=35, p=P(t₃₅>1.5)=0.0713, t₀.₀₅,₃₅=1.6896 → do not reject.
(b) t₀.₀₂₅,₃₅=2.0301, 98±2.0301×2 = [93.9398, 102.0602].
(c) c=95+1.6449×2=98.2897; zβ=(98.2897−98)/2=0.1449 → β=Φ(0.1449)=0.5576, power=0.4424.
Q20　(a) 不拒絕；(b) CI [93.9398, 102.0602] 含 95；(c) β=.5576、power=.4424。δ 只有 3、n 只有 36，抓到的機會不到一半。

四行作答法 / The four-line habit
SE → 統計量 → 臨界值或 p → 判決。這四行寫熟了，任何檢定都只是換公式。前三冊：第一冊練理解、第二冊練覆蓋、這一冊練速度。
SE → statistic → critical value or p → decision. Once these four lines are automatic, every test is just a formula swap. Three sets: Set 1 for understanding, Set 2 for coverage, this one for speed.
