## 三個互動元件

**① §08 拒絕域總表** — 拖 α、拖觀察值 z、切換尾巴型態。
同時看到三件事：拒絕域位置怎麼移動、p 值面積怎麼算、判決為什麼翻轉。這是把「臨界值法」和「p 值法」接起來最有效的一步。

**② §09 檢定力** — 拖 n 和 μₐ。
藍線是 H₀、橙線是真實母體，兩條曲線的**重疊面積就是 β**。把 n 拉大，曲線變瘦、重疊變少、power 上升——「為什麼要加大樣本」在這裡看得見，不用背。

**③ §13 變異數 χ²** — 拖 df。
χ² 是右偏的，所以雙尾檢定的上下界**不對稱**。這個不對稱光看公式記不住，拖幾下 df 就懂了。

## 實作說明

- **零依賴**：統計函數全部自己寫，沒有 MathJax、沒有 Chart.js、沒有 CDN
  - `normCdf` — Abramowitz & Stegun 尾式逼近
  - `normInv` — Acklam 三段有理逼近
  - `lgamma` — Lanczos 近似（g = 7, n = 9）
  - `gammaP` — 級數展開 ＋ 連分式（Numerical Recipes 法）
  - `chi2Inv` — 二分法 160 次迭代
- **圖表**：`<canvas>` 手繪機率密度曲線，依 `devicePixelRatio` 適配
- **數值驗算**：所有臨界值與 p 值均以 `scipy` 重新核算，與頁面函數輸出的誤差 ≤ 2 × 10⁻³（多數到 10⁻⁶）
- **響應式**：側欄在窄視窗自動收合，820 px 以下不出現橫向溢出

## 課件本身的三處筆誤

原始課件有三處印刷錯誤，講義中已用警示框標註，並以正確數值重算：

1. **p.106，Layout B** — 寫 `n₁ = 200, σ₁ = 4.5`，實際應為 `n₂, σ₂`（下標印錯）
2. **p.83，Yilin 的 t 檢定** — 寫 `n = 225`，但同題前文資料為 `n = 25`
3. **p.49，Python 範例** — 使用 `NormalIndPower`（雙樣本函數）且 `alpha = 0.1`，得出 24.66，與手算 `n = 12.34 → 13` 不符。**以手算為準**
